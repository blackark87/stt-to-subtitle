# STT-TO-Subtitles

## 목적
- 영상에서 오디오를 추출 후 LLM을 이용해 한국어 자막을 만들기 위함

## 절차
- ffmpeg 등으로 영상에서 오디오를 추출
- openai, lm studio, aws bedrock, openroute 등 LLM 공급자를 이용 STT로 타임스탬프와 스크립트 작성
- 동일한 공급자에게 스크립트에 대한 번역 요청
- 번역된 결과를 smi, srt, vtt등 jellyfin을 이용한 스트리밍 서비스에 최적화된 파일로 생성

## 환경
- docker를 이용한 컨테이너
- ghcr을 통한 이미지 빌드

## 주의 사항
- 추출된 오디오에서 차량 소리, 전철 소리 등 소음에 의한 노이즈를 분리 해야 한다
- 제대로 인식할수 없는 부분은 전체를 스킵 한다
- 화자가 여러명 일수 있다
- 오디오 언어는 대체적으로 일본어 이지만 영어가 있을 수 있다
